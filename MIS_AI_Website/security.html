Malware and Cyber Threats

The History of Malware: A primer on the evolution of cyber threats

The Elk Cloner Virus in 1982. This virus was created as a practical joke in which the virus would infect a computer's memory via a floppy disk. When an uninfected floppy disc would be added to the computer, it would become infected, by cloning the malware onto it. The virus demonstarted that original info can be written over using malware.

Types of Malware

  1. Ransomware: demands ransoms in return of regaining access to the data
  2. Trojans: malware is disguised as somwthing helpful, later to find out that it is malware

Common Hacker Motives

  1. Financial Gain
  2. Creating Chaos

Prevention Strategies

  • Wireshark: protocol that inspects the network traffic, scanning for anything suspicious
  • Vulnerability Scans: check for any areas that hackers could use to get into the network
